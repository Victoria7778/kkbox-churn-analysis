# KKBox: підписки та драйвери відтоку

Аналіз підписної поведінки користувачів стрімінгового сервісу KKBox: які фактори пов'язані з відтоком (churn) і де втрачаються платники.

**Інструменти:** DuckDB (SQL), Tableau
**Дашборд:** [посилання на Tableau Public] · [PDF](dashboard/dashboard.pdf)

![Дашборд](dashboard/dashboard.png)

## Задача
Зрозуміти, які характеристики підписки й користувача пов'язані з відтоком, як змінювалась виручка та як утримуються когорти нових платників, і запропонувати кроки для зниження відтоку.

## Дані
Датасет [WSDM KKBox Churn Prediction Challenge](https://www.kaggle.com/c/kkbox-churn-prediction-challenge) (Kaggle). Використано три таблиці:
- `members_v3`: профіль користувача (~6,77 млн)
- `transactions`: платежі та плани (~21,5 млн, 2015-01 — 2017-02)
- `train`: мітка відтоку `is_churn` (~993 тис. користувачів)

Не використано: `user_logs` (занадто великий) і файли `*_v2`.

## Методологія
1. Завантаження CSV у DuckDB, перевірка якості даних (дублікати, пропуски, аномалії віку, користувачі без профілю).
2. Очищення: вік поза 10-80 → NULL, перетворення дат `YYYYMMDD`.
3. Таблиця на рівні користувача (`user_features`): параметри останньої підписки, агрегати історії, профіль. `LEFT JOIN` до профілю, щоб не втратити 11,7% користувачів без нього.
4. Churn rate за сегментами, перевірка ефекту складу (чи пояснюють канал і метод оплати різницю поза автопродовженням).
5. Виручка за місяцями та когортний аналіз (частка когорти з платежем у місяці N).
6. Візуалізація в Tableau.

## Ключові результати
Загальний churn: **6,39%**.

- **Автопродовження** головний драйвер: churn 33,1% без нього проти 3,0% з ним. Ця група це 11% користувачів, але ~58% усіх відтоків.
- **Канали й методи оплати** переважно відображають частку користувачів без автопродовження. Усередині групи з автопродовженням churn вирівнюється (2,5-4,9%).
- **Скасування** в останній транзакції: churn 86,6% проти 4,1%.
- **Вік:** від 19,9% (10-17) до 5,6% (50+).
- **Когорти:** найбільший спад у перші 2 місяці (до ~53%), далі крива майже плоска.
- **Виручка:** платників стало майже вдвічі більше (2015 → 2017), виручка зросла на ~30%, середній чек знизився.

## Рекомендації
- Стимулювати вмикання автопродовження вже при першому платежі.
- Запускати утримання для користувачів, що скасували підписку.
- Приділити увагу онбордингу перших двох місяців.

## Обмеження
- Виявлені зв'язки це кореляції, не причинність.
- Вік відомий приблизно для 39% користувачів, коди каналів анонімізовані.
- Нестандартні плани мають малі вибірки.
